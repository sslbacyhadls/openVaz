# OpenVaz

Панель климата для Lada на микрокомпьютере (Orange Pi). Сенсорный экран вместо штатного блока
климата: пять заслонок на сервоприводах, плавный вентилятор, запрос кондиционера в ЭБУ, чтение
температуры охлаждающей жидкости и кодов ошибок по K-Line. Первая машина: Lada Kalina 2010, бензин.

Программа одна, на Rust, на весь экран, без рабочего стола. На компьютере разработчика
панель и автомобиль можно запустить двумя окнами без QEMU. Отдельно доступна проверка панели
в QEMU (обычная ARM-машина, корень только для чтения).

Эмуляторы, прошивка Orange Pi, список комплектующих и схема подключения:
[docs/manual.md](docs/manual.md).

## Быстрый старт: два окна без QEMU

Нужны Rust/Cargo и библиотеки оконного окружения Linux (Wayland или X11).
Из каталога проекта, в первом терминале:

```sh
cargo fetch
emu/panel.sh
```

Во втором терминале:

```sh
emu/car.sh
```

Порядок запуска не важен. Окна соединяются через `emu/build/car.sock`: у автомобиля
появится «панель на связи», на экране ЭБУ панели — температура и коды ошибок. После
перезапуска одного окна связь восстанавливается автоматически. QEMU для этого режима не нужен.

`cargo run --release --bin openvaz` тоже открывает панель с таким подключением.
Не запускайте одновременно вторую панель или QEMU на том же сокете.

## Панель внутри QEMU

Дополнительно нужны `qemu-system-aarch64`, цель Rust `aarch64-unknown-linux-musl`,
`python3`, `parted`, `mke2fs`, `cpio`, `gzip`, `unshare`.

```sh
emu/build-image.sh
emu/run.sh
```

Автомобиль запускается тем же `emu/car.sh` во втором терминале. Подробности:
[docs/manual.md](docs/manual.md).

## Устройство кода

| Файл | Что внутри |
|---|---|
| `src/main.rs` | Запуск панели: окно, `--fb /dev/fb0` или снимок `--dump-ppm` |
| `src/model.rs` | Состояние климата, сохранение настроек, связь с ЭБУ, жесты |
| `src/layout.rs` | Раскладка экрана 1024×600 и попадания по кнопкам |
| `src/paint.rs` | Отрисовка экранов (tiny-skia, fontdue) |
| `src/fb.rs` | Вывод в framebuffer и ввод через evdev (на плате и в QEMU) |
| `src/window.rs` | Окно на хосте (winit, softbuffer), фича `window` |
| `src/link.rs` | Текстовый порт панель ↔ автомобиль |
| `src/connection.rs` | Подключение панели к последовательному порту или сокету эмулятора |
| `src/vehicle.rs`, `src/bin/car.rs` | Эмулятор автомобиля на хосте |
| `emu/` | Сборка диска QEMU, init гостя, запуск |
