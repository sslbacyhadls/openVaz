# Идея проекта

Универсальный модуль на базе микрокомпьютера (Orange Pi, Raspberry Pi) для автомобилей Lada.

## Требования

- Управление воздуховодами сервоприводами.
- Включение и выключение кондиционера.
- Снятие показаний с ЭБУ.
- Все подключения выведены на гребёнку GPIO.
- Экран с сенсорным управлением, картинка по HDMI.

## Первый шаг

Эмулировать сам компьютер через QEMU.

Как эти требования уточнились, записано в [questions.md](questions.md), итоговое железо в
[module.md](module.md).
