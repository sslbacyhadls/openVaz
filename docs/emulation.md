# Запуск эмуляции на компьютере

Панель работает внутри виртуальной машины. Автомобиль: отдельная программа на этом же компьютере.
Пока настоящей Калины нет, эта программа и есть машина: заслонки, вентилятор печки, муфта,
температура жидкости, обороты, скорость и показания выбранной прошивки. Ответы идут панели по
второму последовательному порту. Замеры тока и напряжения для списка деталей снимаются на машине.

## Нужные программы

- `qemu-system-aarch64`
- `rustc` и `cargo`, цель `aarch64-unknown-linux-musl`
- `python3`, `parted`, `mke2fs`, `cpio`, `gzip`, `unshare`

Скрипты сами находят корень проекта (каталог с `Cargo.toml` и папкой `emu`), запускать их можно
из любого места.

Сборка идёт с `--offline`, зависимости cargo берутся из локального кэша. На свежей машине кэш
сначала нужно заполнить, иначе сборка упадёт с `no matching package named ...`:

```sh
cargo fetch
```

## Собрать диск

Один раз и заново после изменений панели или сценария загрузки:

```sh
emu/build-image.sh
```

В конце скрипт пишет путь к `emu/build/disk.img`. Ядро и программы гостевой системы (Alpine)
скачиваются, если их ещё нет в `emu/cache`. Корень системы в госте только для чтения. Раздел
настроек на диске отдельный: положения климата сохраняются между запусками.

## Два терминала

В первом:

```sh
emu/run.sh
```

Открывается окно 1920×1080. Мышь заменяет палец. В этом же терминале видна текстовая консоль
виртуалки. Если осталось окно QEMU от прошлого запуска, закройте его: новое окно заново создаёт
сокет автомобиля.

Во втором:

```sh
emu/car.sh
```

Без имени запускается заводская прошивка `итэлма-м74`. Вторая прошивка:

```sh
emu/car.sh январь-7.2
```

Неизвестное имя печатает список и завершает программу. Скрипт сам собирает эмулятор и
подключается к сокету `emu/build/car.sock`. Порядок запуска терминалов не важен: пока сокета нет,
эмулятор ждёт. Панель раз в секунду повторяет команды, поэтому эмулятор, открытый позже, получает
текущие задания.

В терминале автомобиля таблица на русском: мотор, передача, обороты, скорость, педали, команда и
положение каждой заслонки, задание температуры от 16 до 28 °C, вентилятор, запрос кондиционера и
муфта, температура охлаждающей жидкости, ошибки. Заслонка догоняет команду, вентилятор
раскручивается с запаздыванием, жидкость прогревается примерно до 90 °C. Муфта включается, когда
на экране включён кондиционер, вентилятор уже крутится и мотор не перегрет. При включённом
зажигании мотор уже работает на холостом ходу, чтобы панель сразу видела живые числа.

Клавиши, когда терминал настоящий: газ `W` или стрелка вверх, тормоз `S` или вниз, сцепление `A`
или влево, передачи `1`–`5`, нейтраль `N`, задняя `R`. На русской раскладке те же клавиши: `Ц`,
`Ы`, `Ф`, `Т`, `К`. Зажигание `I` или `Ш`, стартёр `Enter`. Педаль держится, пока клавиша
повторяется, и отпускается, когда повторы прекращаются. Сцепление сходится плавно, поэтому с газом
на первой передаче машина трогается, а брошенное сцепление без газа глушит мотор.

## На панели

Главный экран: климат. Кнопки в нижнем левом углу: лицо, ноги, стекло, рециркуляция,
кондиционер. Ползунок температуры сверху слева, от 16 до 28 °C.

Свайп влево идёт по кругу: климат, ЭБУ, показания, движение. Свайп вправо возвращает на предыдущий
экран. На климате кнопка «Климат» включает удержание заданной температуры по строке `салон`;
пока режим выключен, на кнопке написано «Вручную». Пока эмулятор отвечает, на ЭБУ видны
температура охлаждающей жидкости, строка ошибок и муфта, на показаниях — только каналы выбранной
прошивки, на движении — скорость, обороты, передача, состояние мотора и три педали. Если
остановить `emu/car.sh`, через три секунды эти экраны снова напишут, что связи с ЭБУ нет.

## Остановить

`Ctrl+C` в каждом терминале. Окно панели закрывается вместе с виртуалкой.

## Что пересобирать

| Что изменилось | Что запустить |
|---|---|
| Панель, шрифты, сценарий загрузки гостя | `emu/build-image.sh`, затем `emu/run.sh` |
| Только эмулятор автомобиля | `emu/car.sh` (собирает программу хоста сам) |

## Без QEMU

Для быстрой проверки панель можно запустить прямо на хосте, в окне:

```sh
cargo run --bin openvaz
```

Или снять кадр без окна:

```sh
cargo run --bin openvaz -- --dump-ppm climate.ppm
cargo run --bin openvaz -- --dump-ppm ecu.ppm --screen ecu
```
