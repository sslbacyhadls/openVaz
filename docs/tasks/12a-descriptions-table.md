# 12. Описания прошивок ЭБУ (Итэлма M74, Январь 7.2) и экран показаний

- Приоритет: P3
- Размер: L
- Кто:
- Зависит от: 05
- Статус: открыта

## Зачем

Шаги 2, 3 и 6 из [plan-january.md](../plan-january.md). Панель различает прошивки и показывает
только каналы выбранной. По решению от 2026-11-12 две прошивки: Итэлма M74 (заводская) и
Январь 7.2 (тюнинговая замена).

Начинать после задачи 05: первое описание должно совпасть с блоком, который реально стоит в
машине.

## Что сделать

1. **Таблица описаний** в библиотеке (общая для панели и эмулятора): имя, семейство, строка
   калибровки, протокол, каналы (ключ, название, единица, экран, запрос и формула, источник в
   эмуляторе). Два описания: `итэлма-м74` и `январь-7.2`. Таблица в коде как `const`, без
   файлов и разбора, пока описаний мало.
2. **Порт:** строки `прошивка`, `калибровка`, `показание <ключ> <число>` в `src/link.rs`.
   Чужой ключ пропускается.
3. **Состояние панели:** «нет данных» для ключа, по которому ещё ничего не пришло. Три секунды
   тишины гасят экраны ЭБУ и показаний.
4. **Экран показаний:** два столбца, заголовок с семейством и калибровкой, третий экран в
   круге свайпов.
5. **Эмулятор:** `emu/car.sh итэлма-м74` (по умолчанию) и `emu/car.sh январь-7.2`, неизвестное
   имя печатает список. Код перегрева из описания. Пока модели двигателя нет (задача 16),
   значения можно брать постоянными или из простого генератора.

## Готово, когда

- Тест: у M74 и 7.2 разные наборы ключей, код перегрева у каждого из своего описания.
- Тест: неизвестный ключ не попадает в состояние, тишина 3 с снимает связь.
- В QEMU: `emu/car.sh итэлма-м74` и `январь-7.2` дают разный состав строк на «Показаниях», без
  эмулятора снова «нет связи».
