# 09. Положение заслонок при старте (MCP3208)

- Приоритет: P2
- Размер: M
- Кто:
- Зависит от: 08
- Статус: открыта

## Зачем

По ответу 16.1 при старте программа снимает положение заслонок и возвращает их к сохранённой
цели. Сейчас в `Session::boot` стоит заглушка: «чтение положений: датчиков нет, команда по
сохранённым значениям».

## Что сделать

1. Чтение MCP3208 через `/dev/spidevN.M`: каналы 0-4 потенциометры, канал 5 термистор.
2. Последовательность старта из [module.md](../module.md): прочитать пять потенциометров и
   термистор, задать PCA9685 текущие положения, разрешить OE, плавно повести к сохранённым
   целям.
3. Перевод напряжения в положение по калибровке из задачи 08 (крайние положения в вольтах).
4. Если показание вне диапазона (обрыв провода, серва без питания), заслонку не трогать и
   написать в журнал.
5. В эмуляторе отдавать положения строкой от автомобиля, чтобы проверять это в QEMU.

## Готово, когда

- На столе: серву руками сдвинуть в другое положение, перезапустить программу, серва без
  рывка возвращается к сохранённому.
- Тест на перевод напряжения в положение и на отказ при значении вне диапазона.
