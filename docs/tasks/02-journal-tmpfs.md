# 02. Журнал не на разделе настроек

- Приоритет: P1
- Размер: S
- Кто:
- Статус: открыта

## Зачем

`Journal::open` (`src/model.rs`) пишет `journal.log` в тот же каталог, что и настройки, то есть
на записываемый раздел карты памяти. Файл только растёт: каждое нажатие, каждое изменение
температуры жидкости, каждое «автомобиль отключён». На машине с живым ЭБУ это:

- лишний износ карты памяти, ради защиты которой корень сделан только для чтения;
- риск, что раздел настроек однажды заполнится, и тогда `Climate::save` начнёт падать
  («настройки не записаны»).

При этом `emu/init` уже монтирует `/var/log` как tmpfs, но он не используется.

## Что сделать

Писать журнал в `/var/log/openvaz.log` (tmpfs) или только в stdout, который `init` и так
показывает на консоли. На разделе настроек оставить только `settings`.

Если журнал нужен после перезагрузки для разбора поломок, ограничить его размер: при превышении,
например, 1 МБ переименовать в `.1` и начать заново.

## Готово, когда

- После часа работы с эмулятором на разделе настроек лежит только `settings`.
- `cargo test` зелёный.
