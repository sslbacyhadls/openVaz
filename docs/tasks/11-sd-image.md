# 11. Образ карты памяти для платы

- Приоритет: P2
- Размер: M
- Кто:
- Зависит от: 06
- Статус: открыта

## Зачем

`emu/build-image.sh` собирает диск только для QEMU. Для машины нужен образ под Orange Pi:
корень только для чтения, отдельный раздел настроек, автозапуск панели, ничего лишнего. На карту
попадают только проверенные сборки (ответ 11.1).

## Что сделать

1. Выбрать основу: Armbian minimal для Zero 2 с перемонтированием корня только для чтения или
   Alpine для aarch64 с загрузчиком и ядром от Armbian. Для повторяемости лучше второе: тот же
   `init`, что в QEMU.
2. Разделы: загрузчик и корень только для чтения, раздел настроек `openvaz-data` с `noatime`.
3. Автозапуск тем же `emu/init` или его копией с путями платы (`/dev/fb0`, `/dev/ttyUSB0`).
4. Скрипт сборки рядом с `emu/build-image.sh`, общее вынести, если его больше пары строк.

## Готово, когда

- Карта, записанная из образа, загружается на плате сразу в панель.
- Выключение питания во время перетаскивания ползунка 20 раз подряд не портит ни корень, ни
  настройки (`fsck` чистый, последнее сохранённое положение на месте).
