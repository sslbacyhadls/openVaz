# 14. Живой опрос ЭБУ через ELM327

- Приоритет: P3
- Размер: L
- Кто: не назначена (решить: сторона автомобиля, как эмулятор, или панель)
- Зависит от: 05, 12a
- Статус: открыта

## Зачем

Раздел «Живой адаптер» в [plan-january.md](../plan-january.md). Сейчас все данные ЭБУ присылает
эмулятор. На машине их должен присылать адаптер, и панель при этом не меняется.

## Что сделать

1. Отдельный процесс или поток, который открывает `/dev/ttyUSB0`, инициализирует ELM327
   (протокол из задачи 05), раз в несколько секунд опрашивает каналы текущего описания и пишет
   в панель те же строки, что эмулятор: `охлаждение`, `ошибки`, `показание ...`.
2. Канал с пустым запросом в описании не опрашивается.
3. Адаптер выдернули или он завис: панель через 3 секунды пишет «нет связи», опрос
   переподключается сам.
4. Записанные в задаче 05 сырые ответы использовать как тестовые данные для разбора.

## Готово, когда

- Тесты разбора на реальных ответах из задачи 05.
- На машине: прогрев мотора виден на экране ЭБУ, выдернутый адаптер даёт «нет связи», вставленный
  обратно восстанавливает данные без перезапуска панели.
