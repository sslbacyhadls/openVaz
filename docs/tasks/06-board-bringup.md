# 06. Запуск панели на Orange Pi

- Приоритет: P1
- Размер: M
- Кто:
- Статус: открыта

## Зачем

QEMU даёт обычную ARM-машину с virtio-gpu и virtio-tablet. На плате будет HDMI-контроллер H616,
USB-сенсор через хаб и другой набор устройств ввода. Пока программа не запущена на настоящей
плате с настоящим экраном, неизвестно, работают ли `src/fb.rs` (framebuffer, разрешение) и ввод
через evdev с реальным сенсором.

## Что сделать

1. Сверить плату по надписи: Orange Pi Zero 2, H616, 512 МБ. Записать сюда.
2. Поставить Armbian для этой платы на отдельную карту (это отладочная система, не итоговый
   образ).
3. Собрать `cargo build --release --target aarch64-unknown-linux-musl --no-default-features`,
   скопировать `openvaz` на плату.
4. Подключить экран 1024×600 по HDMI и сенсор через хаб вместе с ELM327.
5. Запустить `openvaz --fb /dev/fb0`. Проверить разрешение, касания по кнопкам, свайп.
6. Снять потребление памяти (`ps -o rss`) и загрузку процессора при перетаскивании ползунка.

## Готово, когда

- Записано: модель платы, версия Armbian и ядра, что показал `fbset` или `/sys/class/graphics/fb0`.
- Панель на экране, касания попадают туда же, куда в QEMU.
- Сенсор и ELM327 одновременно видны через хаб (`lsusb`, `/dev/input/event*`, `/dev/ttyUSB0`).
- Записаны RSS и загрузка процессора.
