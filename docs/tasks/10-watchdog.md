# 10. Сторожевой таймер

- Приоритет: P2
- Размер: S
- Кто: Александр (панель)
- Зависит от: 08
- Статус: код готов, перезагрузка гостя не прогнана

## Зачем

По [module.md](../module.md): если программа перестала обслуживать выходы, плата
перезагружается, а подтяжки держат вентилятор и запрос кондиционера выключенными. В коде
сторожевого таймера пока нет. `emu/init` перезапускает упавшую программу, но не зависшую.

## Что сделать

1. Открыть `/dev/watchdog` в главном цикле (`src/fb.rs`), кормить его в том же цикле, который
   обслуживает выходы.
2. Тайм-аут через `WDIOC_SETTIMEOUT`, например 5 секунд. Главный цикл должен просыпаться чаще.
3. Для QEMU: в `emu/run.sh` добавить `-device i6300esb` или в госте модуль `softdog`, чтобы
   поведение проверялось без платы.

## Готово, когда

- В QEMU: `kill -STOP` процесса `openvaz` через 5-10 секунд перезагружает гостя.
- На плате: то же, плюс светодиод запроса кондиционера гаснет сразу после остановки.
