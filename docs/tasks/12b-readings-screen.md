# 12b. Экран показаний на панели

- Приоритет: P3
- Размер: M
- Кто: Александр (панель)
- Зависит от: 12a
- Статус: сделано

## Зачем

Панельная часть шагов 3 и 6 из [plan-january.md](../plan-january.md): панель принимает строки
от автомобиля по контракту из 12a и показывает только каналы выбранной прошивки.

## Что сделать

1. **Состояние панели:** текущая прошивка и калибровка, значения по ключам. Ключ, которого нет в
   текущем описании, пропускается. «Нет данных» для ключа, по которому ещё ничего не пришло.
   Три секунды тишины гасят экраны ЭБУ и показаний.
2. **Экран показаний:** два столбца, заголовок с семейством и калибровкой, третий экран в круге
   свайпов.
3. Файлы эмулятора (`src/vehicle.rs`, `src/bin/car.rs`, `emu/car.sh`) не трогать. Для проверки
   без эмулятора Влада подавать строки в порт тестом.

## Готово, когда

- Тест: неизвестный ключ не попадает в состояние, тишина 3 с снимает связь.
- Снимки `--dump-ppm` экрана показаний для обеих прошивок: разный состав строк.
- После 12c в QEMU: `emu/car.sh итэлма-м74` и `январь-7.2` дают разный состав строк на
  «Показаниях», без эмулятора снова «нет связи».
