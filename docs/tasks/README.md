# Задачи

Задачи нарезаны из [plan-january.md](../plan-january.md), из списка «До включения на машине» в
[module.md](../module.md) и из разбора кода. Пометок TODO в коде нет.

Одна задача: один файл. Внутри: зачем, что сделать, когда готово, от чего зависит. Взял задачу:
впиши себя в поле «Кто». Закрыл: поменяй статус здесь и в файле.

Приоритеты:

- **P1:** снимает главный риск или мешает работать уже сейчас. Делать первым.
- **P2:** нужно для первого запуска на машине.
- **P3:** следующий этап (прошивки Итэлма M74 и Январь 7.2, живой ЭБУ).
- **P4:** можно отложить или пересмотреть.

## Кто что делает

Решение от 2026-11-12: работаем параллельно, каждый на своей стороне текстового порта.

| Сторона | Кто | Файлы |
|---|---|---|
| Панель | Александр | `src/model.rs`, `src/layout.rs`, `src/paint.rs`, `src/fb.rs`, `src/window.rs`, `src/main.rs`, `emu/build-image.sh`, `emu/run.sh`, `emu/init`, `emu/initramfs-init` |
| Эмулятор автомобиля | Влад | `src/vehicle.rs`, `src/bin/car.rs`, `emu/car.sh` |
| Машина и плата | Влад | Замеры, наклейка ЭБУ, запуск на Orange Pi |
| Контракт между сторонами | оба | `src/link.rs` (строки порта), таблица описаний прошивок, раздел «Текстовый порт» в [plan-january.md](../plan-january.md) |

Правила:

- В файлы чужой стороны не лезть. Нужна правка там: попросить владельца или договориться в PR.
- Контракт меняется только отдельным маленьким PR, который одобрили оба. Сначала контракт,
  потом каждый делает свою сторону. Так ветки не конфликтуют.
- Задача с двумя сторонами режется на части (как 12a, 12b, 12c).

## Порядок

Главный риск проекта не в коде панели, а в железе и в ЭБУ: какой блок стоит в машине, говорит ли
с ним ELM327, что замыкает кнопка кондиционера. Поэтому задачи на машине (05-07) стоят рядом с
быстрыми правками кода и идут раньше большого плана по прошивкам.
