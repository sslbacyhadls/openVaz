# 12c. Эмулятор под две прошивки

- Приоритет: P3
- Размер: M
- Кто: Влад (эмулятор)
- Зависит от: 12a
- Статус: закрыта

## Зачем

Эмуляторная часть шагов 2 и 6 из [plan-january.md](../plan-january.md), раздел «Эмулятор»:
автомобиль на хосте притворяется выбранной прошивкой и шлёт панели строки по контракту из 12a.

## Что сделать

1. `emu/car.sh итэлма-м74` (по умолчанию) и `emu/car.sh январь-7.2`. Неизвестное имя печатает
   список описаний и завершает программу.
2. Слать `прошивка`, `калибровка` и `показание` только для каналов выбранного описания.
3. Код перегрева брать из описания.
4. Числа показаний брать из модели двигателя: обороты, скорость, дроссель, впрыск, кислород.
5. Экран показаний не рисовать. Панель только принимает строки контракта и хранит числа, иначе
   новые сообщения не собираются. Отрисовка остаётся в задаче 12b.

## Готово, когда

- Тест в `vehicle.rs` или `car.rs`: для каждой прошивки наружу уходят только её ключи.
- `emu/car.sh` без имени запускает `итэлма-м74`, с неизвестным именем печатает список.
