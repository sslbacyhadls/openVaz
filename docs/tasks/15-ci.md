# 15. CI: тесты и сборка под aarch64

- Приоритет: P3
- Размер: S
- Кто: Александр

- Статус: закрыта

## Зачем

Проверки сейчас запускаются только руками. Когда в проекте двое, ошибку в чужом PR дешевле
поймать автоматически.

## Что сделать

GitHub Actions на каждый PR и пуш в `master`:

1. `cargo fmt --check`
2. `cargo clippy --all-targets -- -D warnings`
3. `cargo test --no-default-features`
4. `cargo build --release --target aarch64-unknown-linux-musl --no-default-features`

Линкер этой цели — `rust-lld` (`.cargo/config.toml`): системный `ld` не принимает флаг Cortex-A53. В GitHub Actions каталог `rust-lld` добавляется в `PATH`. Clippy собирает и оконную версию, поэтому на раннере ставятся заголовки X11 и xkbcommon.

Образ QEMU в CI не собирать: долго, нужен `unshare`.

## Готово, когда

PR с намеренно сломанным тестом показывает красную проверку, исправленный показывает зелёную.
