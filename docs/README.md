# Документация OpenVaz

Читать в таком порядке:

1. [project.md](project.md): идея и требования одним абзацем.
2. [questions.md](questions.md): все решения по плате, машине, заслонкам, ЭБУ и экрану. Самый
   полный источник правды: если документы расходятся, смотреть сюда, особенно раздел
   «Уточнения после проверки».
3. [module.md](module.md): железо модуля, схема, каналы, список деталей.
4. [emulation.md](emulation.md): как запустить панель в QEMU.
5. [plan-january.md](plan-january.md): план следующего этапа.
6. [tasks/](tasks/README.md): задачи, нарезанные из плана, из списка «До включения на машине»
   и из разбора кода.
